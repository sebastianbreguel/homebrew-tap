# homebrew-tap

Homebrew tap for [SoftFocus](https://github.com/sebastianbreguel/softfocus) and other apps.

## Install SoftFocus

```bash
brew install --cask sebastianbreguel/tap/softfocus
```

That auto-adds the tap. To open it:

```bash
open -a SoftFocus
```

Look for the 👁 icon in the menu bar.

## Update / uninstall

```bash
brew upgrade --cask softfocus
brew uninstall --cask softfocus
```
